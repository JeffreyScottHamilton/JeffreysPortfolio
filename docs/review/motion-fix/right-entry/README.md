# Rightward entrance and portrait color

Scrolling brings the opening previews in from the right, with captions attached. The portrait moves left as before; the project reel also enters horizontally. The hero ribbon straightens into a leading line, and the opening ribbon's existing particles gather into the preview frame outlines. This is a reversible GSAP scroll transition; no horizontal scroll trap or new navigation is added.

Hover brings the original photograph's RGB colors into the same moving portrait points. Color travels with the points, blends softly around the cursor and follows their settling wake. Point opacity/count and fluid motion remain intact. The desktop photo canvas is not revealed through a hole. The Canvas fallback uses the same sampled colors.

The recordings in this directory are from the local production build. Deployment remains owner-managed.
